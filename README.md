## AvatarLegacy 

This is the AvatarLegacy core plugin! 


## Description 

AvatarLegacy is a Avatar: The Last Airbender inspired RPG in minecraft, with all modificiations and work running server side, without any client side mods. I created this project in summer 2024 and have been working on it ever since. The server is currently at 330 members, and future work for AvatarLegacy v2 has been started, with a complete overhaul of all mechanics!

## Getting Started 

**Dependencies** 
- A minecraft server 
- Minecraft server version of 1.21-1.21.11 
- The Paper minecraft server software [ https://papermc.io ] 

**Installing** 
- Drop the .jar [Located in releases] into your server's /plugins folder 
- Restart the server 

**Pre-installed enviroment:** 
- Join the server at ip: `avatarlegacy.skailarhost.com` 
- Contact `@fishymc` on discord or member ID: `U0BKLQCUTQQ` on slack for help joining
